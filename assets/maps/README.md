# Scenario maps

These files are the six StarCraft II Marine micromanagement scenes configured by `src/sc2env/config.py` and evaluated in the accompanying SAGE manuscript.

| SAGE key | File | Runtime map name |
| --- | --- | --- |
| `sce-1` | `local_enemy_test_1.SC2Map` | `local_enemy_test_1` |
| `sce-1m` | `local_enemy_test_1_mirror.SC2Map` | `local_enemy_test_1_mirror` |
| `sce-2` | `MarineMicro_MvsM_4_dist.SC2Map` | `MarineMicro_MvsM_4_dist` |
| `sce-2m` | `MarineMicro_MvsM_4_dist_mirror.SC2Map` | `MarineMicro_MvsM_4_dist_mirror` |
| `sce-3` | `MarineMicro_MvsM_8_far.SC2Map` | `MarineMicro_MvsM_8_far` |
| `sce-3m` | `MarineMicro_MvsM_8_far_mirror.SC2Map` | `MarineMicro_MvsM_8_far_mirror` |

Install a local StarCraft II client and copy these maps into its `Maps/` directory before running live-game commands. SAGE does not redistribute the StarCraft II client or game assets; users are responsible for complying with the applicable StarCraft II license.
