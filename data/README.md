# Included baseline data

This release includes one compact trajectory/BK-Tree artifact per evaluation scenario. They provide end-to-end examples for the ETG and visualisation code. They are not the full training corpus used for large-scale experiments.

| Scenario | Included directory |
| --- | --- |
| `sce-1` | `MarineMicro_MvsM_4/6` |
| `sce-1m` | `MarineMicro_MvsM_4_mirror/3` |
| `sce-2` | `MarineMicro_MvsM_4_dist/1` |
| `sce-2m` | `MarineMicro_MvsM_4_dist_mirror/3` |
| `sce-3` | `MarineMicro_MvsM_8/1` |
| `sce-3m` | `MarineMicro_MvsM_8_mirror/1` |

Generated collections, resampled datasets, and experiment outputs remain local by design.
